# 桌面管理

一款面向 Windows 的本地优先桌面收纳工具。产品核心不是替换资源管理器，而是把桌面视为一个“收件箱”：发现待处理项目、生成整理计划、预检通过后直接归档，并支持完整撤销。

## 当前阶段

项目已完成桌面整理与收纳窗口功能闭环。WPF 应用既提供不接触真实桌面的临时目录演示，也支持对用户选择的真实监控目录生成计划，并在快照校验和执行预检通过后直接整理。

## 查看低保真原型

双击 `prototypes/desktop-inbox-prototype.html`，或在 PowerShell 中运行：

```powershell
.\scripts\open-prototype.ps1
```

原型提供三种结构完全不同的首页方案，可通过底部切换器或键盘左右方向键切换。原型中的整理操作仅改变页面内存状态，不会移动真实文件。

## 运行安全演示应用

已安装 .NET 10 SDK 后，在 PowerShell 中运行：

```powershell
.\scripts\run-demo.ps1
```

应用中的“准备演示文件”只会在系统临时目录 `DesktopManager.Demo` 下创建模拟文件。当前流程支持扫描、生成只读计划、执行前快照校验与磁盘预检、风险摘要、安全重名、SQLite 操作历史、逐项结果详情、跨启动撤销和中断操作对账。异常恢复只核对源路径与目标路径的实际状态，不会自动继续移动文件。

“真实桌面”入口会使用 Windows 返回的实际桌面位置，并监听新增、删除、重命名和内容变化。隐藏、系统、未完成下载及常见临时文件不会进入收件箱。保存有效托管目录后，可以生成指向真实托管目录的 `Draft` 预览；预览本身不创建目录、日志或移动文件。

设置页可把主监控目录改为另一个现存目录，并可叠加显示 Windows 公共桌面。公共桌面项目始终只读，只参与收件箱展示和规则影响预览，不进入整理计划。文件监听按变化路径增量更新；监听缓冲区异常时才回退到完整快照。

“设置”页面可以选择并保存真实整理的监控目录与托管目录。桌面目录与托管目录相同或互相包含时会被底层整理模块拒绝。配置保存在 `%LOCALAPPDATA%\DesktopManager\settings.json`。

真实整理不需要长期确认、会话授权、批量上限或文本确认。点击“立即执行”后，计划通过最新快照校验和执行预检便直接运行；源路径越界、重解析点、空间不足等阻断项仍会拒绝执行，目标重名始终安全改名而不覆盖。

演示操作与真实桌面操作使用相互独立的 SQLite：演示数据库位于临时目录，真实数据库位于 `%LOCALAPPDATA%\DesktopManager\real-operations.db`。历史页面会按时间合并展示并标注范围；启动恢复分别使用各自的源目录和托管目录白名单，避免跨范围撤销或恢复。

“规则”页面支持组合扩展名、文件名关键词、最小/最大大小、最近修改天数和项目类型条件，并支持显式优先级、启用/停用、删除和恢复默认规则。不同种类条件采用 AND，同类候选采用 OR；规则与安全设置一同保存在 `%LOCALAPPDATA%\DesktopManager\settings.json`，任何规则变更都会作废当前整理计划。

若一个项目命中的最高优先级规则给出不同归档目标，预览会显示规则冲突与全部候选目标，并禁用整个计划的执行入口；同优先级且目标相同的规则会合并说明，不视为冲突。

“规则与收纳”入口同时提供规则编辑和收纳窗口管理。每个不同的规则归档目标映射为一个桌面伴随窗口；多条规则指向同一归档子目录时共用一个窗口。窗口展示目录中的实际文件、文件夹和快捷方式，并使用 Windows Shell 返回的原始图标。窗口支持拖动、缩放、折叠、网格/列表模式、逐个显示隐藏、自动排列和自定义名称，布局随设置保存。所有收纳窗口只使用无模糊、无纹理、无动态效果的透明表面；外观可选纯色或从上到下的双端渐变，并支持每个窗口单独设置或一键应用到全部窗口。点击“从桌面取色”会读取当前壁纸，提取主色以及与主色差异最大的次色，再生成具有明显明暗差且适合白色文件名的低亮度纯色和渐变色；读取失败不会覆盖当前颜色。表面透明度只在主设置页调整，纯色与渐变色共用同一个数值，文件图标与文字始终完整不透明。

桌面组件现包含收纳窗口，以及唯一的“快速应用”、日历和“待办事项”窗口。快速应用可拖入文件、文件夹和程序，也可新增 `http/https` 或 `www.` 网址；支持双击或 Enter 打开单项、多选后打开部分内容、一键打开某个分组或全部内容。快捷目标可在新增或编辑时选择已有分组或输入新分组，旧数据自动归入“未分组”。待办事项顶部提供“无日期＋今天起未来 7 天”的日期导航，默认选中今天；列表只展示当前日期的事项，有事项的日期显示红点，新事项也直接归入当前日期。事项行不重复日期、不设置优先级、不使用筛选页签，而是在同一列表内自动分为高对比度的“未完成”和“已完成”两组。四类桌面组件都只通过标题栏移动，内容空白区不带动特殊窗口。“关闭”只隐藏特殊窗口并保留内容、位置和大小，再次启用会恢复。应用退出前会抓取三种特殊窗口的最终启用状态、内容与布局并原子写入设置，重启后按原状态恢复。日历窗口显示月历、2026 年中国大陆法定节假日与调休上班标记，法定假日、调休和普通周末分别使用分层色块，并保留“休/班”文字；周末调休上班日优先显示“班”。没有内置官方数据的年份不会推测调休日期。四类窗口统一挂接 Windows 桌面宿主层，共享松开后吸附、防重叠、相邻尺寸匹配、缺口填补和边角缩放规则，并由托盘“显示全部/隐藏全部”共同控制。

文件可以直接拖入收纳窗口完成移动，也可以从窗口拖出；右键或 `Ctrl+C` / `Ctrl+V` 可通过 Windows 标准文件剪贴板复制粘贴文件与文件夹，支持和资源管理器互通，同名目标自动生成安全名称且不覆盖。在同一窗口内拖到另一个项目位置会调整显示顺序并自动保存，不改变实际文件路径。`Ctrl+↑`、`Ctrl+↓` 和右键“上移/下移”提供等效排序入口。收纳窗口内容空白区用于拖动框选，按住 `Ctrl` 可追加选择；单击空白区会取消选择，空白区右键可按首字母、大小、类别或修改日期快速排序，其中类别会把相同文件后缀排列在一起，并按后缀 A–Z 排列，结果同样按目录保存。双击文件夹会在窗口内进入下一层，并提供返回导航。窗口聚焦后输入项目名称首字母可循环快速定位。右键或键盘可定位、复制、粘贴、重命名、移动到其他目录或删除到 Windows 回收站。窗口只通过标题栏移动，文件操作立即生效，不生成整理计划或确认流程；同名目标会自动生成安全名称而不会覆盖。主窗口缩到托盘后收纳窗口继续运行，托盘右键可显示或隐藏全部收纳窗口，退出应用时全部关闭。

在预览中选中冲突行并点击“处理选中冲突”，可以为当前计划选择一个已有候选；选择不会修改规则，重新生成计划后需重新裁决。规则页面支持编辑和复制，保存规则变更仍会立即作废当前计划。

整理预览支持编辑当前草稿：可多选后从计划排除、只保留选中执行项，也可为单个计划项改选托管目录内的归档子目录。修改目标时文件名保持不变，且不能越过托管目录；这些调整既不移动文件，也不写回规则或项目偏好，重新生成计划即可恢复原始建议。存在未裁决冲突时，“仅执行选中项”不可用，不能借批量筛选绕过冲突裁决。

整理计划顶部显示可执行项和已知总大小，并以“冲突 / 本次排除”区分阻断项与用户临时决定。展开“计划统计与风险”可查看目标目录分布、未知文件夹大小及计划内目标同名风险；文件夹不会为了统计而递归读取。点击立即执行后会再次校验源项目并完成执行预检。

执行前预检会检查路径边界、源项目缺失或占用、内部重解析点、目标介质、已知磁盘空间和重名风险；阻断项存在时执行器自身也会拒绝。文件和文件夹均支持归档，跨卷文件夹使用托管目录暂存副本完成安全迁移。撤销形成独立历史记录，可恢复整批剩余项目或单项，并在原位置冲突时选择安全改名、跳过或桌面范围内的新路径。

收件箱项目可设为“保留”或“忽略”：保留项继续显示，但不参与规则建议和托盘待整理计数；忽略项不进入扫描结果或变化通知。所有项目处置偏好保存在设置 JSON，并可在设置页恢复到收件箱。偏好按完整路径识别，项目重命名后视为新项目；任何偏好变更都会作废当前整理计划。

收件箱支持按名称搜索，并组合项目类型、最近修改时间和大小区间筛选；筛选只改变当前视图，不修改扫描快照或整理计划。列表直接显示大小与修改时间，文件夹因大小未知而不进入具体大小区间。使用 `Ctrl` 或 `Shift` 多选后，可一次批量加入收藏夹、设为保留或设为忽略；批量设置只写入一次配置，保留/忽略会使当前计划失效。

收藏夹提供不移动文件的多标签逻辑分组：一个桌面项目可以同时加入多个收藏夹。收藏夹支持新建、重命名、删除和成员移除；可用成员可以在资源管理器中定位，但不会由应用直接打开或执行。项目被移动、重命名或暂时不可用时，成员关系会保留并显示为“已失效”，用户可从当前演示桌面或真实桌面的现存项目中重新绑定，也可批量清理当前收藏夹的全部失效关系。收藏夹随设置持久化，并纳入备份恢复与路径边界校验。

设置页可把规则、通知设置、全局快捷键、项目处置偏好和分范围操作历史导出为 `.dmbak` 备份包。导入先校验格式版本、ZIP 条目和本机路径边界，再展示恢复摘要并等待确认；越界偏好与历史会跳过，开机启动状态不会从备份恢复。

应用启用单实例保护。重复启动时第二个进程不会创建新窗口，而是通知已运行实例从最小化状态恢复并前置；进程异常退出后 Windows 会自动释放实例锁。

关闭主窗口会隐藏到系统托盘并继续监听桌面变化。托盘提示和“打开收件箱”菜单会显示当前待整理数量；双击图标可恢复窗口，只有托盘“退出应用”才真正结束进程。系统注销或关机时会正常退出，不会被关闭到托盘逻辑阻止。

应用运行期间可使用全局快捷键恢复窗口并直接打开收件箱，即使窗口已隐藏到托盘也有效。默认组合为 `Ctrl + Alt + Space`，设置页可改为包含至少两个修饰键，并搭配 `Space`、`A–Z`、`0–9` 或 `F1–F12` 的组合。新组合注册成功后才会保存；若被占用则恢复旧组合，启动时已保存组合被占用则回退默认组合。退出应用时会注销快捷键。

设置页可选择是否随 Windows 登录启动，默认关闭。启用后只写入当前用户的启动项，不需要管理员权限；登录时应用携带 `--background` 参数启动并直接驻留系统托盘，不主动弹出主窗口。

设置页还可控制托盘状态通知和免打扰时段，默认开启通知并在 `22:00–08:00` 静音。桌面变化、整理完成和撤销完成只会在主窗口隐藏时通知；关闭通知或处于免打扰时段时，普通状态提示会被抑制，快捷键冲突等故障警告仍会显示。

诊断中心显示应用、Windows、.NET 与进程架构摘要，并可导出最近 2000 条诊断事件。事件按天写入 `%LOCALAPPDATA%\DesktopManager\Logs` 并保留 7 天；个人目录前缀、其他盘符绝对路径和 UNC 路径会脱敏。诊断 ZIP 不包含设置 JSON、SQLite、文件内容或用户名。

运行全部测试：

```powershell
.\scripts\test.ps1
```

## 构建与验证 Windows 安装器

生成 `win-x64` 自包含单文件安装程序：

```powershell
.\scripts\publish-installer.ps1 -Version 1.11.4 -RuntimeIdentifier win-x64
```

脚本依据 [.NET 单文件部署说明](https://learn.microsoft.com/dotnet/core/deploying/single-file/overview)生成自包含应用，再由 Inno Setup 6 编译为标准 Windows 安装向导，因此目标电脑不需要预装 .NET。输出位于 `artifacts/release`，同时生成同名 `.sha256` 校验文件。

验证安装器的哈希、未签名状态、隔离安装、原位升级、应用启动和卸载：

```powershell
.\scripts\verify-installer-package.ps1 `
  -InstallerPath .\artifacts\release\DesktopManager-Setup-1.11.4-win-x64.exe `
  -ExpectedVersion 1.11.4
```

当前发行版为 `1.11.4 win-x64`，最低目标为 Windows 10 1809。用户直接运行 `DesktopManager-Setup-1.11.4-win-x64.exe`，通过标准安装向导安装到当前用户目录，无需解压或管理员权限；开始菜单、可选桌面快捷方式、升级覆盖和 Windows 卸载入口由安装器统一管理。设置与操作历史位于独立的 `%LOCALAPPDATA%\DesktopManager`，升级和默认卸载都会保留。发行版固定保持未签名，不执行 Authenticode 或时间戳验证，Windows 可能显示“未知发布者”或 SmartScreen 提示。

## 已确定的产品原则

- Windows 11 优先体验，同时支持 Windows 10 1809 及以上版本。
- 本地单机优先，MVP 不要求账号或云服务。
- 整理前必须预览，文件移动必须可追溯、可撤销。
- MVP 不永久删除文件，不静默执行高风险规则。
- 先完成“扫描 → 计划 → 执行 → 撤销”的纵向闭环，再扩展 AI、同步和桌面容器。
