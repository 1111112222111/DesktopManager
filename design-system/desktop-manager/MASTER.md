# Desktop Manager 设计系统：静奢玻璃（Quiet Luxury Glass）

> 状态：项目级唯一视觉规范。自 2026-08-24 起，主应用、桌面收纳窗口、对话框及后续新增功能均默认遵循本文件。若页面需要偏离，必须在 `pages/` 下记录偏离原因，不得直接引入另一套视觉语言。

## 1. 设计主张

桌面管理是一件应当安静发生的事。界面不与文件争夺注意力，而是通过精确对齐、克制的层次和稳定的反馈建立信任。

三个关键词：**简约、精确、静奢**。

- 简约：减少容器与重复说明；一个视觉区域只承担一个任务。
- 精确：使用一致的网格、发丝边框、数据字体和明确状态。
- 静奢：质感来自材质与比例，不来自高饱和色、炫光或大量渐变。

标志性元素是“**归档脊线**”：香槟金细线表示当前位置、选中项、规则与收纳去向的连续关系。它是唯一允许稳定出现的装饰性强调。

## 2. 设计令牌

真实代码来源：`src/DesktopManager.App/Themes/QuietLuxury.xaml`。文档与代码发生冲突时，先确认设计意图，再同步修改二者；不得只改一处。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| Ink / 黑曜 | `#181B1A` | 主文字、主按钮、最高层级结构线 |
| Graphite / 石墨 | `#626966` | 正文说明、次级信息 |
| Muted / 雾灰 | `#7B837F` | 标签、时间、非关键数据 |
| Porcelain / 钛白 | `#F2F4F1` | 应用背景 |
| Surface / 釉白 | `#FCFDFC` | 输入框、浮层与内容表面 |
| Line / 发丝线 | `#D6DBD7` | 分隔线、控件边界 |
| Champagne / 香槟金 | `#AA8959` | 归档脊线、焦点、关键选中态 |
| Champagne Deep | `#87683F` | 浅底上的小型强调文字 |
| Sage / 灰鼠尾草 | `#3F6154` | 成功、运行中、安全状态 |
| Danger / 灰红 | `#A94A45` | 错误与不可逆风险，不作装饰 |

桌面组件状态层补充：`GlassControlBrush`、`GlassControlHoverBrush`、`GlassControlPressedBrush` 用于轻量按钮交互；`GlassSelectionFillBrush`（`#24AA8959`）用于桌面组件内容区的拖动框选范围；`GlassDangerTextBrush` 与 `GlassSuccessTextBrush` 只承载深色桌面组件上的逾期、完成等语义文字，并必须配合状态文案；收纳窗口只使用透明表面，纯色或渐变色由持久化颜色设置生成，不叠加纹理、折射、模糊或动态光学层；`GlassHolidayBrush`、`GlassAdjustedWorkdayBrush` 与 `GlassWeekendBrush` 仅用于日历日期色块，并必须同时显示“休 / 班”文字。

禁止：新增页面直接使用旧森林绿 `#237A57`、高饱和蓝紫色或彩虹状态色。

## 3. 字体

- 展示与标题：`Bahnschrift` → `Segoe UI Variable Display` → `Microsoft YaHei UI`。
- 正文与控件：`Segoe UI Variable` → `Microsoft YaHei UI`。
- 路径、时间、编号、统计：`Cascadia Mono` → `Consolas`。
- 页面标题 32px / SemiBold；区块标题 17px / SemiBold；正文 13–14px；辅助信息不低于 11px。
- 中文正文不使用衬线字体，不使用全大写英文作为大面积装饰。

## 4. 空间、圆角与层级

- 采用 4/8 基础节奏：4、8、12、16、24、32、40、48。
- 页面外边距：常规窗口 32–48；紧凑窗口 20–24。
- 控件最小高度：常规按钮 40；图标按钮 40×40；输入控件 36。
- 常规圆角 9；内容表面 12；桌面收纳窗口 16。
- 主应用最多三级表面：背景 → 内容表面 → 临时浮层。避免卡片套卡片。
- 阴影只表示真正悬浮的窗体或弹层；列表和普通卡片依赖边框与留白，不依赖重阴影。

## 5. 主应用布局

```text
┌ 导航 214 ┬──────────────────────── 工作区 ────────────────────────┐
│ 品牌     │ 页面标题                              次要 / 主要操作 │
│          │ ─── 香槟金归档脊线 + 单条状态数据带 ─────────────── │
│ 四项导航 │ 主要内容：列表、规则或设置                          │
│          │                                                      │
│ 状态摘要 │ 页面级状态                                  操作栏 │
└──────────┴──────────────────────────────────────────────────────┘
```

- 左侧导航使用浅色表面；选中项为白色、香槟金圆点/脊线和轻微层次。
- 一级导航固定为“收件箱、规则与收纳、历史、设置”；不再提供收藏夹入口。
- 页面只保留一个深色主按钮；同一层级其余操作均为描边或文字按钮。
- 统计优先合并为连续数据带，不拆成多个悬浮卡片。
- 规则和收纳窗口属于同一概念，界面文案统一使用“规则与收纳”。
- 所有表格的表头、数据行和内容边界共享同一列起点；数据行不得用额外左边框或整体内边距破坏列对齐。
- 表格行级编辑、复制、启停和删除统一收进最右侧“操作”列的单一下拉菜单，避免横向堆叠按钮；列表下方只放新增或当前编辑所需的表单。
- 新增规则只强制填写名称和归档子目录；规则条件可全部留空，留空表示匹配全部项目，并在列表中显示“全部项目”。
- 主应用滚动条使用 4px 圆角滑块；悬停加深，拖动时使用香槟金，禁止退回系统默认滚动条。

## 6. 桌面收纳窗口

- 窗体使用深石墨半透明表面；透明度必须保证文件名可读，不追求“越透明越高级”。
- 1px 冷白边缘，不使用外围投影；标题栏保持窄、平、无色块。
- 桌面收纳窗口不显示归档脊线；香槟金只用于焦点、滚动条拖动和主应用选中态。
- 文件图标必须来自 Windows Shell 原始图标，不重绘、不套色、不加统一底板。
- 空状态使用细虚线圆环和明确文案：“拖入文件，保留原始图标与格式”。
- 拖放不是唯一操作方式；必须保留打开目录、键盘打开、重命名和菜单操作。
- 网格/列表切换使用双状态矢量图标；列表视图无表头、无横向滚动条。
- 纵向滚动条使用 4px 半透明圆角滑块，Hover 增亮，拖动时使用香槟金。
- 窗口不显示底部状态栏；运行状态通过主应用或操作反馈承载。
- 折叠与展开必须使用方向明确且会随状态切换的双状态矢量图标。
- 收纳窗口必须挂接到 Windows 桌面宿主层，不参与普通应用窗口切换；“显示桌面”后仍留在桌面，不使用“始终置顶”模拟桌面层。
- 移动过程中允许收纳窗口互相覆盖，不执行实时布局修正；松开鼠标后再一次性消除重叠并吸附，窗口之间保持 6px 间距，避免拖动时跳位或振动。
- 窗口位于上下两个邻窗之间时，松开后自动填满二者之间的垂直缺口；仍保留 6px 间距，并以上方邻窗宽度为优先对齐基准。
- 只有标题栏可拖动窗口；内容空白区改为拖动框选，文件项目、滚动条、导航按钮等交互控件不得触发窗口移动。
- 内容框选越过系统最小拖动距离后显示 1px 香槟金描边与低强调半透明填充，并选择相交的可见项目；`Ctrl` 拖动在原选择上追加，单击空白区清除选择。
- 文件夹在收纳窗口内逐层进入；非根层级显示紧凑返回导航。窗口聚焦后，字符键按当前区域设置不区分大小写循环定位同首字母项目。
- 文件项目支持在当前目录视图内拖拽排序，排序只改变显示顺序并持久化，绝不改动真实文件路径；拖出窗口仍使用系统文件拖放。必须同时提供右键“上移/下移”以及 `Ctrl+↑`、`Ctrl+↓` 键盘替代入口。
- 单击内容空白区或标题栏必须清除当前文件选中态；文件项目与空白区域的右键菜单必须严格分流，避免在无选中项目时显示文件操作。
- 内容空白区右键提供当前目录快速排序：首字母 A–Z、文件大小从大到小、类别、修改日期最新优先。其中“类别”表示按文件后缀不区分大小写 A–Z 分组，同后缀内再按名称 A–Z；文件夹优先，无后缀项目最后。快速排序结果写入同一套目录级显示顺序，不改动真实文件。
- 文件项目右键菜单提供复制、粘贴和“删除（移入回收站）”；空白区右键菜单提供粘贴。`Ctrl+C` 与 `Ctrl+V` 必须使用 Windows 标准文件剪贴板，可与资源管理器互通。粘贴在后台执行，同名项目安全改名且不覆盖，文件夹复制不得阻塞界面线程。
- 移动结束后，左右相邻窗口统一高度并优先匹配左侧窗口；上下相邻窗口统一宽度并优先匹配上侧窗口。
- 边框缩放期间使用 18px 尺寸感知距离：调整宽度时与上、下相邻窗口比较，调整高度时与左、右相邻窗口比较，接近即匹配相同尺寸。
- 缩放只允许被拖动的边改变；左边固定右边、右边固定左边、上边固定下边、下边固定上边。缩放完成后的防重叠也必须遵守同一锚定规则。
- 四角等比例缩放在一次拖拽开始时锁定宽度或高度为驱动轴，拖拽期间不得反复切换驱动轴。
- 无系统右下角缩放箭头。四条边分别支持水平或垂直缩放，四个角支持保持当前宽高比的缩放；可命中边缘宽度为 7px。
- 每个收纳窗口标题栏提供独立设置入口，只设置透明表面的填充方式和颜色：纯色使用一个颜色，渐变色使用起始色与结束色；不再提供材质选项。具体规范见 `pages/collection-window-materials.md`。
- 表面透明度是全局唯一设置，所有窗口、纯色与渐变色共用，单窗口设置不得保存或覆盖自己的透明度。透明度只作用于背景，不能降低文件图标与文字透明度。桌面宿主模式下不提供置顶选项。
- 外观设置提供“从桌面取色”：读取当前 Windows 桌面壁纸，提取主色与次主色后生成适合白色文字的低亮度纯色和渐变色；不得直接使用可能破坏对比度的壁纸原色。读取失败时给出原因并保留当前设置。
- “应用到所有窗口”必须同时更新全局默认外观并清除现有窗口的单独颜色覆盖，使当前及后续新增收纳窗口立即保持一致。

## 7. 图标与交互

快速应用、日历与待办事项窗口的视觉覆盖和交互细则见 `pages/desktop-widgets.md`；它们与收纳窗口共同构成“桌面组件”，共享桌面宿主和全局显示/隐藏入口。

应用品牌图标使用“2×2 桌面网格 + 香槟金归档脊线”构图：深石墨圆角底板、钛白窗口块和单条香槟金竖线，不使用文字、文件夹隐喻或高饱和色。正式资产为 `src/DesktopManager.App/Assets/DesktopManager.png`，Windows 多尺寸资源为同目录 `DesktopManager.ico`；可执行文件、安装快捷方式和托盘必须使用同一图标来源。

- 结构图标使用同一套线性矢量路径或 Segoe Fluent Icons 字形，禁止 Emoji。
- 独立图标按钮必须有 `AutomationProperties.Name` 或可见文本提示。
- Hover 150–220ms，Pressed 不改变布局尺寸；禁用态同时降低表面与文字强调。
- 键盘焦点使用 2px 香槟金焦点环，不能移除焦点可见性。
- 颜色不得作为唯一状态信号，状态必须同时包含文字或形状。

## 8. 文案语气

- 使用用户能识别的对象和主动动词：“立即收纳”“扫描桌面”“打开目录”。
- 避免把实现机制写进主界面，如“执行门禁”“会话授权”。必要技术信息放在诊断或帮助中。
- 空状态说明下一步；错误说明发生了什么以及如何处理，不使用模糊的“操作失败”。

## 9. 新功能验收清单

- [ ] 只使用语义化资源令牌，没有新增散落的主题色值。
- [ ] 一个页面只有一个主要操作。
- [ ] 无 Emoji 结构图标，独立图标按钮有无障碍名称。
- [ ] 正常文字对比度不低于 4.5:1，控件边界与图标不低于 3:1。
- [ ] 键盘焦点清晰，操作顺序与视觉顺序一致。
- [ ] 800×600 最小窗口下内容可滚动且不被固定操作栏遮挡。
- [ ] 高对比度模式仍可读取和操作。
- [ ] 收纳窗口继续使用 Windows Shell 原始文件图标。
- [ ] 收纳窗口吸附后互不重叠，边缘和四角均可缩放，折叠图标状态正确。
- [ ] 若引入视觉例外，已在 `pages/` 记录原因和范围。
- [ ] 待办事项的日期选择、完成、编辑与删除均有键盘入口；未完成/已完成在同一列表分组，逾期与完成状态不只依赖颜色。
