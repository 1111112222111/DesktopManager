# 收纳窗口透明表面覆盖

> 适用范围：收纳窗口标题栏设置入口、单窗口外观设置对话框、主应用“窗口设置”和窗口背景。未列出的规则继承 `MASTER.md`。

## 单一材质

- 收纳窗口只保留透明材质，不再提供玻璃、水晶、钻石或其他材质选项。
- 背景只能是纯色或双端线性渐变；不使用系统模糊、纹理、折射、切面、暗角、外围阴影或指针跟随效果。
- 纯色与渐变色共享设置页的全局表面透明度。文件图标、文件名、控件和焦点环保持完整不透明。
- 渐变方向固定为从上到下，减少多余参数；顶部起始色承担壁纸主色相，底部结束色承担次色相与深度，两端必须有一眼可辨的明暗和色相差，同时保持白色文件名可读。
- 每个窗口可以保存自己的填充方式与颜色。“恢复默认”清除单窗口覆盖，重新继承全局设置。

## 桌面自动取色

- “从桌面取色”读取当前 Windows 桌面壁纸；优先读取系统壁纸路径，找不到时回退到当前用户主题缓存。
- 对壁纸进行降采样与颜色分桶，提取覆盖面积最大的主色；次色从主要候选色中选择与主色 RGB 距离最大的颜色，不能因单个高亮像素或图标产生偏色。
- 生成色必须保留壁纸色相但压低亮度：顶部色映射到较亮的深色层，底部色映射到明显更暗的层；主次色过近时进一步压暗底部色，不能把高亮壁纸原色直接作为窗口颜色。
- 自动取色同时生成推荐纯色、渐变起始色与渐变结束色，并按当前选中的填充方式更新预览；用户仍可继续手动修改。
- 读取或解析失败时显示明确原因，不覆盖当前颜色。

## 设置对话框

- 顶部仅提供“纯色 / 渐变色”两个有文字的单选项，不出现材质术语。
- 颜色行使用 Windows 原生颜色选择器。纯色模式显示一个颜色；渐变模式显示起始色和结束色。
- “从桌面取色”是次要操作；“应用到当前窗口”和“应用到所有窗口”是两个含义明确的提交操作。
- “应用到所有窗口”更新全局默认并清除全部单窗口颜色覆盖；必须在按钮文案或辅助文字中明确这一影响范围。
- 对话框不提供透明度控件，只显示“透明度由设置页统一控制”。

## 高对比度与兼容

- 高对比度模式使用 Windows 系统窗口色与文字色，忽略自定义纯色和渐变色但保留设置数据。
- 旧版本保存的材质枚举允许被 JSON 忽略；迁移后使用纯色模式和原主颜色，不中断窗口恢复。
