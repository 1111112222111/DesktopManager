# 桌面组件视觉覆盖：快速应用、日历与待办事项

> 适用范围：快速应用、日历窗口、待办事项窗口。未列出的规则全部继承 `MASTER.md`。

## 原因

这三类窗口没有文件管理密度，但仍与收纳窗口共同驻留桌面。它们沿用深石墨半透明玻璃、窄标题栏、冷白发丝边缘和无外围阴影，以形成同一桌面组件家族。

快速应用、日历与待办事项都是唯一特殊窗口。主应用使用“启用 / 关闭”而不是“新增 / 删除”；关闭只停止显示，保留窗口内容、位置与大小。

## 持久化

- 快速应用的启用状态、名称、全部快捷目标、分组、窗口位置、大小和可见性均写入设置；日历的启用状态、位置、大小和可见性同样保存；待办事项还要保存全部任务、完成状态与截止日期。快捷日期条只是下一次新增的临时输入，不随应用重启保存。
- 应用退出前必须从仍在运行的特殊窗口抓取最终状态并原子写入设置，随后才关闭窗口；程序内部同步或退出不得被解释为用户点击“关闭”。
- 重启应用时先恢复特殊窗口定义，再创建窗口；已启用窗口不得恢复为关闭，快捷目标和分组不得回到空集合。
- 连续两次真实应用启动的冒烟测试必须验证上述状态，避免只验证一次序列化而漏掉退出覆盖。

## 共用布局与移动

- 特殊窗口与收纳窗口使用同一套桌面布局规则，并参与跨类型防重叠。
- 特殊窗口与收纳窗口都只允许通过标题栏移动；内容区域不承担窗口移动手势。
- 移动过程中允许临时覆盖；松开后才吸附、匹配相邻尺寸并填补上下缺口，窗口间隙统一为 6px。
- 四边和四角使用 7px 命中区；边框缩放保持未拖动边不变，四角保持宽高比，接近相邻窗口尺寸时自动匹配。
- 不显示系统右下角缩放箭头，不在移动过程中反复修正位置。

## 快速应用

- 每行只呈现原始 Shell 图标、名称和目标类型；网址使用线性链接图标。
- “打开选中”是主要操作，“全部打开”是次要操作；支持多选和 Enter 打开。
- 新增入口位于标题栏，编辑与删除放入项目右键菜单，避免常驻按钮拥挤。
- 空状态明确提示可拖入文件、文件夹或程序，也可新增网址。
- 标题栏除操作按钮外全部为拖动命中区，包括标题文字之外的透明空白；项目和操作按钮保留自身交互，不触发移动。
- 内容空白区不移动窗口，也不启动框选；单击空白区只清除当前选择。桌面组件中只有收纳窗口提供空白区框选。
- 快捷目标按用户分组展示；旧数据和未指定分组的目标归入“未分组”。新增或编辑时可选择已有分组，也可直接输入新分组名称。
- 分组标题是低强调的信息层级，不做成厚重卡片；右侧提供紧凑的“打开本组”按钮，组内仍呈现原始 Shell 图标、名称、类型与单项打开入口。
- 新增/编辑对话框不重复显示窗口标题和功能介绍，直接进入地址、名称与分组字段；常规窗口高度内完整呈现表单和底部操作，不依赖滚动条。
- 对话框保留明确字段标签、实时地址校验和始终可见的底部操作区；确认按钮具有默认按钮语义，校验失败时就地说明原因。

## 日历窗口

- 使用 7 列月历网格，不使用绝对定位；周标题与日期列严格对齐。
- 今日使用冷白描边，法定假日使用香槟金文字并附“休”，调休上班日使用灰鼠尾草并附“班”；状态不只依赖颜色。
- 月份切换按钮保留无障碍名称与清晰键盘焦点，返回今日提供文字按钮。
- 节假日当天使用低饱和香槟色半透明色块，同时保留“休”和节日名称；调休上班日使用灰鼠尾草色块和“班”，颜色不是唯一状态信息。
- 未内置官方安排的年份明确显示“暂无官方调休数据”，不推测调休日期。
- 普通周六、周日使用比法定假日更低强调的冷白半透明色块并显示“休 / 周末”；若官方数据将周末列为调休上班日，则“班”状态覆盖普通周末标记。

## 待办事项

- 窗口名称统一使用“待办事项”，不使用错别字“代办事项”。标题栏只保留名称、未完成数量、清理已完成与关闭按钮，完整空白区域仍可拖动窗口。
- 标题栏下方首先显示紧凑时间轨：一个“无日期”选项，加上从今天开始连续 7 天。日期以“今天 / 明天 / 周几”和本地化月日双行显示，使用原生互斥选择、明确选中表面、键盘焦点与无障碍名称。
- 时间轨同时承担日期导航和下一条事项的日期输入；默认选择今天。切换日期后，列表只展示该日期的事项；“无日期”用于查看和新增未指定日期的事项。按 `Enter` 或点击线性新增按钮时，新事项直接归入当前日期，空标题就地提示，不打开额外确认流程。
- 有事项的日期在日期文字下显示 4px 红点，红点只作数量存在提示，当前日期仍由原生互斥选中表面、焦点和无障碍名称共同表达。
- 不显示“待办 / 全部 / 已完成”筛选。当前日期的事项位于同一个纵向滚动区，按“未完成”和“已完成”两个原生分组连续呈现；分组标题显示名称和数量，不承担点击或折叠操作，并显式使用 `GlassTextBrush`，不得继承为黑色。
- 列表行只呈现完成开关和任务名称，不重复显示已经由顶部时间轨表达的事项日期，也不显示、保存或排序优先级。完成项使用删除线和“已完成”分组语义，不只依赖变色。
- 默认顺序为：未完成在前；未完成项中逾期优先、有截止日期的从近到远、同日按名称；已完成项按最近完成时间排列。
- 双击或 `F2` 编辑任务，`Space` 完成 / 恢复，`Delete` 删除；右键菜单提供同等操作。编辑窗口只包含名称和可选截止日期，不使用滚动条。
- “清理已完成”作为标题栏低强调图标动作，只移除当前日期的已完成任务；必须有无障碍名称和 ToolTip，不弹出文本确认，不影响其他日期和未完成任务。
- 列表使用 `ObservableCollection`、原生分组和虚拟化；不得出现横向滚动条。当前日期没有事项时，空状态必须指出当前查看日期并提示从上方新增。

## 验收补充

- 快捷目标可由键盘多选并打开；失败项目汇总反馈，不因一个目标失败而中止其余目标。
- 三类窗口均挂接桌面宿主层，不进入 Alt+Tab，不使用置顶模拟。
- 标题栏图标按钮使用无边框静默态，仅在 Hover / Pressed 时显示轻量状态层；内容操作使用同高 32px 的半透明胶囊按钮，不使用主应用的实心大按钮。
- 文字与图标本身保持不透明，透明度只作用于玻璃表面。
