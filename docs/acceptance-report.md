## 2. 本版功能结论

| 范围 | 结论 |
| --- | --- |
| 应用品牌图标 | 新增“2×2 桌面网格 + 香槟金归档脊线”图标；PNG 保留真实透明圆角，ICO 包含 16–256px 九档尺寸 |
| 图标一致性 | 可执行文件、安装快捷方式与托盘从同一应用图标来源显示，不再使用 Windows 默认程序图标 |
| 待办日期导航 | 顶部显示无日期及今天起连续 7 天并默认选择今天；列表只展示选中日期，新事项也直接归入该日期 |
| 待办日期提示 | 有事项的日期显示 4px 红点，删除最后一项后红点消失；选中态、焦点和无障碍名称仍独立存在 |
| 待办单页分组 | 当前日期事项在同一滚动列表内按未完成/已完成分组；分组标题显式使用玻璃高对比度文字，不再显示为黑色 |
| 待办精简行 | 事项行只显示完成开关和名称，不重复显示事项日期；完成项使用删除线并移入已完成分组 |
| 待办键盘操作 | Enter 新增、Space 完成/恢复、F2 编辑、Delete 删除、Esc 清除选择；右键提供等价操作 |
| 特殊窗口持久化 | 退出前强制抓取快速应用、日历与待办事项的最终状态；启用状态、内容、位置、大小和可见性原子保存 |
| 重启回归 | 桌面组件冒烟连续启动两次，每次检查三种特殊窗口的内容、状态与布局未被清空 |
| 单一透明表面 | 删除玻璃、水晶、钻石及全部光学叠层，只保留无模糊、无纹理、无指针效果的透明背景 |
| 纯色与渐变 | 纯色使用一个颜色；渐变使用可编辑的顶部起始色和底部结束色，二者共享全局透明度 |
| 桌面自动取色 | 读取当前壁纸或 Windows 纯色背景，提取主色及差异最大的次色，并生成具有明显明暗差的低亮度适配色 |
| 全部应用 | 单窗口弹窗和主设置页均支持一键应用到全部收纳窗口，同时清除旧单窗口外观覆盖 |
| 标题栏信息 | 收纳窗口标题栏仅显示窗口名称，不再显示收纳项目数和规则数量，减少视觉噪声 |
| 单窗口设置 | 每个收纳窗口标题栏提供独立齿轮入口；弹窗支持纯色/渐变、手动选色、桌面取色、当前应用、全部应用及恢复默认 |
| 独立颜色 | 每个收纳窗口可保存自己的填充模式和颜色，重启后保持 |
| 全局透明度 | 设置页的“全局表面透明度”是唯一透明度来源，所有窗口、纯色与渐变共用；旧单窗口透明度不再覆盖它 |
| 旧配置迁移 | 旧材质字段由 JSON 兼容忽略，保留原主颜色并自动迁移为纯色，不中断窗口和布局恢复 |
| 特殊窗口移动 | 快速应用、日历与待办事项均只通过完整标题栏移动；按钮保持自身交互，内容空白区不拖动窗口 |
| 收纳窗口框选 | 内容空白区改为拖动框选并支持 `Ctrl` 追加；只有标题栏负责移动窗口 |
| 框选反馈 | 越过系统最小拖动距离后显示香槟金描边的低强调选择框；松开或失去鼠标捕获后立即收起 |
| 快速应用新增/编辑 | 去掉重复大标题和说明，使用无滚动条紧凑表单；确认按钮始终位于底部并支持 Enter，错误原因就地显示 |
| 快速应用输入 | 支持 `www.` 网址自动补全 `https://`、带引号路径及环境变量路径 |
| 快速应用分组 | 新增或编辑时可选择/输入分组；窗口按组展示并支持“一键打开本组”，旧项目自动归入“未分组” |
| 日历窗口 | 月历显示 2026 年法定节假日与调休上班标记；未知年份不推测官方调休安排 |
| 桌面组件宿主 | 收纳、快捷、日历、待办四类窗口均挂接 Windows 桌面层，并纳入托盘统一显示/隐藏 |
| 特殊窗口唯一性 | 快捷、日历和待办各最多一个；启用/关闭替代新增/删除，关闭后保留内容和布局 |
| 跨类型自适应布局 | 四类窗口共享 6px 间距、松开后吸附、防重叠、相邻尺寸匹配、缺口填补和边角缩放规则 |
| 特殊窗口视觉 | 按钮改为静默图标与半透明胶囊层级；节假日和调休使用语义色块并保留文字标记 |
| 周末标记 | 普通周六、周日显示低强调“休·周末”色块；官方调休上班日覆盖为“班” |
| 窗口自动布局 | 移动结束后消除重叠并吸附；位于上下邻窗之间时自动填满垂直缺口，保持 6px 间距 |
| 托盘快捷操作 | 应用托盘图标右键菜单支持显示或隐藏全部收纳窗口 |
| 收纳窗口拖动 | 仅标题栏可拖动；项目、按钮、滚动条和内容框选不会误触发窗口移动 |
| 首字母定位 | 窗口聚焦后输入首字母，不区分大小写循环定位同首字母项目 |
| 文件夹浏览 | 双击或按 Enter 进入下一层；提供返回按钮和 Backspace 返回；不能越过收纳区根目录 |
| 嵌套文件操作 | 在子文件夹中仍可重命名、移出和移入回收站；区域外路径继续被拒绝 |
| 窗口内排序 | 文件可拖到同窗口的其他位置调整显示顺序，按目录持久化；拖出窗口仍使用系统文件移动 |
| 选中状态 | 点击标题栏或内容空白区清除当前项目选中，文件右键菜单与空白右键菜单严格分流 |
| 快速排序 | 空白区右键支持首字母、大小、类别和修改日期；类别按文件后缀 A–Z 分组，同后缀内按名称排列 |
| 剪贴板操作 | 文件右键支持复制、粘贴和回收站删除；空白区支持粘贴；Ctrl+C/Ctrl+V 与资源管理器互通 |
| 视觉规范 | 延续“静奢玻璃”设计语言，导航使用紧凑半透明层、Fluent 图标及明确无障碍名称 |

## 4. 建议人工验收路径

1. 解压发行包，双击 `Install.cmd`。
2. 打开任一收纳窗口，点击齿轮按钮切换纯色与渐变色，分别修改颜色并应用；确认窗口没有模糊、纹理、切面或动态光效。
3. 点击“从桌面取色”，确认颜色来自当前壁纸但经过低亮度适配；再点击“应用到所有窗口”，确认全部窗口立即统一并清除原单窗口颜色。
4. 在设置页调整“全局表面透明度”，确认纯色和渐变窗口同步变化，文件图标与文字保持不透明；重启后再次确认填充模式、颜色和全局透明度均保留。
5. 进入“规则与收纳 · 窗口”，启用“快速应用”；从标题栏文字以外的空白处拖动，确认窗口可移动，标题栏按钮和内容空白区都不会误触发移动。
6. 新增快速应用，分别验证 `www.` 网址、文件、文件夹和程序；确认实时提示会说明地址是否有效，鼠标点击“添加应用”与 Enter 都能完成确认。
7. 新增“工作”和“娱乐”两个分组，确认窗口按组展示；点击“打开本组”确认只启动该组项目；右键编辑现有项目并更换分组，重启后确认分组保留。
8. 添加日历窗口，切换月份，确认节假日“休”和调休“班”均有文字标记；退出并重启应用，确认快速应用的启用状态、目标、分组、布局及日历启用状态和布局全部恢复。
9. 启用“待办事项”，确认默认选择今天；分别在今天和明天用 Enter 新增事项，确认相应日期出现红点，切换日期时只显示该日事项且事项行不重复日期。
10. 完成今天的一项事项，确认它仍停留在今天并移入“已完成”分组；分组标题为清晰浅色而不是黑色。点击“清理已完成”，确认只清理今天，不影响明天。
11. 删除某日期最后一项，确认该日期红点消失；按 F2 编辑、Delete 删除，并验证 Space 完成/恢复与 Esc 取消选中。
12. 关闭并重新启用待办事项，退出并重启应用，确认任务、完成状态、位置和大小完整恢复；重新打开时默认查看今天。
13. 右键任务栏通知区域中的“桌面管理”图标，分别验证隐藏和显示全部桌面组件。
14. 把一个窗口拖到上下两个窗口之间并松开，确认它自动填满缺口且窗口互不重叠。
15. 从收纳窗口内容空白处拖过多个文件，确认出现框选范围且窗口不移动；按住 `Ctrl` 再框选，确认追加选择。
16. 把一个文件拖到同窗口中的另一个项目位置，确认只改变显示顺序；重启后确认顺序保留。再把它拖出窗口，确认系统文件拖放仍然有效。
17. 使用 `Ctrl+↑`、`Ctrl+↓` 及右键“上移/下移”验证键盘替代操作。
18. 选中一个项目后单击标题栏或内容空白处，确认选中态清除；空白处右键确认只显示四种快速排序，而不是文件操作。
19. 依次验证首字母、大小、类别和修改日期排序，并重启确认当前目录顺序保留。
20. 右键复制文件后在空白区右键粘贴，确认原文件保留且副本安全命名；再用 `Ctrl+C` / `Ctrl+V` 与资源管理器双向复制文件夹。
21. 右键选择“删除（移入回收站）”，确认文件进入 Windows 回收站。
22. 单击窗口后输入 `A` 等首字母，确认匹配项目被选中；重复输入应循环到下一个匹配项。
23. 双击窗口内文件夹进入下一层，验证返回按钮和 Backspace；在子层执行重命名或移出。
24. 运行 `Uninstall.cmd`，确认应用移除且默认保留用户设置。

Windows 可能因未签名而显示“未知发布者”或 SmartScreen 提示，这是当前本机自用发行策略的预期行为。
