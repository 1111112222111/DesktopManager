# 收纳窗口挂接 Windows 桌面宿主层

用户明确要求收纳窗口不参与普通应用窗口切换，并在“显示桌面”后继续作为桌面内容存在。因此收纳窗口优先挂接 Explorer 的桌面图标宿主层；若该宿主不可用或因 DPI 模式拒绝挂接，则回退到 Windows 根桌面窗口。窗口使用子窗口样式且不再提供“始终置顶”。

桌面挂接封装在 `DesktopWindowHost`，WPF 窗口只接收成功状态，不直接枚举 Shell 窗口。冒烟测试要求所有可见收纳窗口完成桌面挂接。Explorer 私有宿主结构可能随系统更新变化，因此必须保留根桌面回退路径。

窗口移动与缩放遵循单写入者原则：移动期间允许临时重叠，松开后由 WPF 布局协调器一次性消除重叠、吸附并匹配邻窗尺寸；原生缩放期间禁止 `LocationChanged` 或 `SizeChanged` 再次改写矩形，只由 `WM_SIZING` 按被拖动边完成尺寸匹配。四角等比例缩放在一次交互内锁定驱动轴，避免宽高驱动来回切换。
