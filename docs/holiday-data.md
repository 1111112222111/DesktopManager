# 日历窗口节假日数据

日历窗口采用离线内置的年度数据，不在后台联网，也不推测尚未公布的调休安排。

## 2026 年

- 数据范围：中国大陆法定节假日及调休上班日。
- 官方来源：[国务院办公厅关于 2026 年部分节假日安排的通知](https://zwfw.gansu.gov.cn/huixian/zczx/tzgg/art/2025/art_715c16a75e4d4c289c295e77772c7274.html)，国办发明电〔2025〕7号。
- 内置日期：元旦、春节、清明节、劳动节、端午节、中秋节、国庆节，以及通知列明的调休上班日。

打开没有内置数据的年份时，窗口只显示公历日期并提示“该年份暂无官方调休数据”。年度通知发布后，应新增该年份的目录数据和覆盖测试，不修改历史年份。
