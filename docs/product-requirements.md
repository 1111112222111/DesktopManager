# 桌面管理产品需求文档

> 状态：正式验收版 v1.1  
> 日期：2026-08-24

## 1. 产品概述

桌面管理是一款 Windows 本地优先的桌面收纳软件。它把桌面当作一个待处理收件箱，持续发现新项目，根据可解释规则生成整理计划，并在预检通过后直接执行归档；规则目标还会映射为可直接管理文件的桌面收纳窗口。计划整理留下可撤销历史，窗口直接操作即时生效且删除固定进入 Windows 回收站。

产品的核心承诺是：**看得清、收得快、敢使用。**

## 2. 目标与非目标

### 2.1 MVP 目标

1. 帮助用户快速了解桌面上有哪些待处理项目。
2. 用可解释的规则减少重复分类劳动。
3. 通过预览、冲突提示、历史和撤销建立信任。
4. 跑通“扫描 → 生成计划 → 预检后直接执行 → 撤销”的完整闭环。
5. 通过桌面收纳窗口直接查看和管理规则目标目录中的文件。

### 2.2 MVP 非目标

- 不替换 Windows 资源管理器。
- 不直接控制原生桌面图标位置。
- 不接管或重新排列 Windows 原生桌面图标。
- 不管理其他应用的窗口布局。
- 不提供在线 AI、账号、云同步和团队协作。
- 不永久删除用户文件。
- 不进行注册表清理或系统优化。
- 不承诺 macOS 或 Linux 支持。

## 3. 目标用户

### 3.1 主要用户

- 经常把截图、文档、压缩包和安装包临时放在桌面的办公用户。
- 同时处理多个项目，需要快速找到最近资料的知识工作者。
- 想保持桌面整洁，但不愿每天手工移动文件的用户。
- 对自动整理存在顾虑，要求每次变更可解释、可恢复的用户。

### 3.2 核心痛点

- 桌面逐渐堆积，用户不知道先处理什么。
- 手工分类耗时，目录结构难以长期坚持。
- 普通自动整理工具过于激进，用户担心文件找不到或被覆盖。
- 仅按扩展名整理无法表达“项目”“临时”“保留”等真实意图。

## 4. 产品原则

1. **边界明确**：真实文件变更必须通过目录边界、源状态和目标介质预检，不覆盖已有文件。
2. **计划与执行分离**：整理计划可在内存中显式编辑，但编辑不接触文件系统、不写回规则；点击立即执行后才产生整理操作。
3. **结果可解释**：用户能看到项目命中了哪条规则、将移到哪里。
4. **失败可恢复**：单项失败不能掩盖其他结果，应用重启后历史仍存在。
5. **本地优先**：MVP 不需要账号和网络即可完成核心工作。
6. **可解释执行**：先展示建议和风险，再由用户点击立即执行；阻断项必须先解决。

## 5. 核心用户旅程

### 5.1 首次使用

1. 软件说明不会永久删除文件，并展示默认监控位置。
2. 用户确认桌面位置和托管目录。
3. 软件执行只读扫描并展示收件箱。
4. 软件给出若干默认规则示例，但不直接移动文件。
5. 用户生成首个整理计划，检查后执行。
6. 首页展示本次结果和撤销入口。

### 5.2 日常整理

1. 桌面出现新项目。
2. 托盘显示待整理数量，但不过度打扰。
3. 用户打开收件箱，选择全部或部分项目。
4. 软件展示建议动作、命中规则、目标位置和冲突。
5. 用户修改选择后点击立即执行。
6. 软件展示成功、跳过、失败的明确结果。

### 5.3 撤销整理

1. 用户从最近操作或历史页面发起撤销。
2. 软件检查原位置是否可恢复。
3. 若原位置冲突，先提示重命名、跳过或选择新位置。
4. 撤销结束后记录结果，不覆盖原操作历史。

## 6. MVP 功能需求

### F-01 桌面位置识别

- 获取当前用户真实桌面位置，不写死路径。
- 支持桌面被 OneDrive 或系统策略重定向的情况。
- 公共桌面默认只读展示，是否允许整理需单独授权。

当前实现进度：系统桌面解析、自定义主监控目录和公共桌面只读叠加已完成；公共桌面不会进入整理计划。

### F-02 扫描与变化监听

- 识别文件、文件夹、快捷方式和基础元数据。
- 支持手动刷新。
- 新增、删除、重命名和移动后更新收件箱。
- 默认排除系统文件、隐藏文件和临时下载文件。

### F-03 收件箱

- 展示名称、类型、大小、创建或修改时间、建议分类。
- 支持按最近新增、长期未处理、类型和大小筛选。
- 支持单选、批量选择和全选。
- 清楚区分文件、文件夹与快捷方式。

当前实现进度：名称搜索、类型/修改时间/大小组合筛选、大小与修改时间展示、扩展多选，以及批量收藏/保留/忽略已完成。筛选不改变扫描快照或整理计划；保留与忽略批量变更会作废计划。

最近新增、长期未处理、创建时间判定和显式全选已完成。

### F-04 规则

- 支持扩展名、文件名关键词、大小、时间和项目类型条件。
- 规则拥有启用状态和显式优先级。
- 可预览规则会影响哪些桌面项目。
- 同一项目命中优先级相同且归档目标不同的规则时，标记冲突，不自动决定。

当前实现进度：扩展名、文件名关键词、大小、最近修改时间和项目类型条件，以及规则编辑/复制、启用状态、显式优先级、持久化管理、最高优先级冲突检测和候选展示均已完成。冲突默认阻止整个计划执行；用户可从已有候选中逐项目裁决，全部解决后再直接执行，裁决不修改规则。

规则页面会基于当前扫描快照展示命中项目，并标记公共桌面只读命中。

### F-04A 收藏夹

- 收藏夹是逻辑分组，不复制或移动桌面项目。
- 一个桌面项目可以属于多个收藏夹，重复加入同一收藏夹保持幂等。
- 支持新建、重命名、删除收藏夹和显式移除成员。
- 项目路径失效时保留成员关系并清楚标记，不自动迁移到同名项目。
- 可用成员只允许在资源管理器中定位，不由应用直接打开或执行。
- 失效成员可重新绑定到当前桌面的现存项目，或在单个收藏夹内批量清理。

当前实现进度：收藏夹页面、多标签成员关系、资源管理器定位、单关系重新绑定、失效关系批量清理、设置持久化，以及带路径边界过滤的备份恢复已完成。

### F-05 整理计划

- 显示原位置、建议动作、目标位置和命中规则。
- 支持逐项取消和修改目标位置。
- 支持多选后仅保留选中执行项；存在未裁决冲突时不得用该能力绕过裁决。
- 展示计划中的项目数、总大小、冲突数和风险提示。
- 生成计划不得改变任何真实文件。

当前实现进度：逐项或批量从当前草稿排除、仅保留选中执行项，以及单项修改托管目录内的目标子目录已完成。计划编辑不持久化、不修改规则或项目处置偏好；修改目标保留文件名并受托管目录边界校验，重新生成计划会恢复规则建议。

计划摘要已完成：展示可执行数、排除数、冲突数、已知总大小和目标目录分布，并提示未知文件夹大小与计划内目标同名风险。文件夹大小不递归读取，摘要与执行预检使用相同计算口径。

### F-06 执行整理

- MVP 支持四类用户结果：收藏夹承担不移动文件的逻辑分组，整理执行器承担归档移动，项目处置偏好承担保留和忽略。
- 归档文件进入用户授权的托管目录。
- 目标重名时不得覆盖，必须采用安全命名或等待用户决定。
- 单项失败不回滚已成功项目，但必须准确记录部分成功结果。
- 正在下载、被占用或权限不足的项目应跳过并说明原因。

当前实现进度：文件与文件夹归档、跨卷文件夹安全迁移、目标安全命名、逐项失败记录和双重执行预检已完成。预检覆盖源占用、重解析点、目标介质和已知空间；执行器自身再次强制阻断项。

### F-07 历史与撤销

- 每次整理形成不可丢失的操作记录。
- 支持查看每个操作项的原路径、目标路径和结果。
- 支持单项恢复和整批撤销。
- 应用重启后仍可读取未完成或已完成操作。
- 撤销本身也形成记录，不篡改原始历史。

当前实现进度：独立撤销记录、整批剩余项目撤销、单项撤销、跨启动可撤销性计算，以及安全改名/跳过/新路径三种冲突处置已完成；旧 SQLite 会自动增加兼容列。

### F-08 托盘与快捷访问

- 支持最小化到系统托盘。
- 托盘显示待整理数量和打开收件箱入口。
- 支持全局快捷键；默认使用 `Ctrl + Alt + Space`，允许用户配置受限安全组合并在占用时回退。
- 开机启动默认关闭，由用户主动开启。

当前实现进度：关闭到托盘、待整理数量、打开收件箱、明确退出、单实例激活、可配置全局快捷键及冲突回退，以及用户主动开关的后台开机启动已完成。

### F-09 设置

- 配置受监控桌面位置与托管目录。
- 管理忽略项和保留项。
- 配置通知、开机启动和快捷键。
- 通知支持总开关与可跨午夜的免打扰时段，前台使用应用时不重复弹出状态提示。
- 提供元数据与操作记录备份入口。
- 提供脱敏诊断摘要与用户主动导出入口。

当前实现进度：开机启动、全局快捷键自定义、通知总开关、免打扰时段、隐藏状态通知、保留项/忽略项管理、带版本和路径安全预检的备份恢复，以及脱敏诊断包导出入口已完成。

### F-10 安装与升级

- 提供不依赖预装 .NET 的 Windows x64 自包含发行包。
- 安装和 Shell 集成限制在当前用户范围，不要求管理员权限。
- 同一安装目录可原位升级，失败时恢复旧版本。
- 升级和默认卸载保留设置与操作历史；彻底清理必须显式选择。
- 卸载清理开机启动项、快捷方式和系统卸载登记。
- 发行包附带 SHA256；本机自用版本固定不签名、不验签，但必须完成 Windows Sandbox 安装与卸载验收。

当前实现进度：`win-x64` 自包含发行包、Windows 10 1809+ 目标、批处理脚本目录显式传递与回退、Known Folder 默认路径回退、生命周期脚本、跨版本升级，以及 Windows Sandbox 中安装器、收纳窗口 UI 和卸载器实机验收已完成。后续版本固定 `signed=false`，发布与 Sandbox 流程均不包含签名参数或验签步骤。

### F-11 桌面收纳窗口

- 每个不同的规则归档目标形成一个收纳区；多条规则指向同一相对目录时共享一个桌面收纳窗口。
- 收纳窗口展示对应收纳区当前实际存储的直接子项，不要求项目必须由本应用归档。
- 窗口支持拖动、缩放、折叠、显示/隐藏、网格/列表模式、名称与颜色设置，并持久化布局。
- 文件系统变化经过短时间合并后自动刷新；单窗口最多直接渲染前 200 项。
- 用户可在窗口中直接拖入、拖出、打开、定位、重命名、移出和删除项目，不生成整理计划或确认流程。
- 窗口项目使用 Windows Shell 根据实际路径返回的原始文件、文件夹或快捷方式图标。
- 同名拖入和移出自动使用安全名称，不覆盖现有项目；删除发送到 Windows 回收站，不执行永久删除。
- 停用规则不删除收纳区或文件；删除最后一条关联规则只移除窗口映射，不删除目录内容。
- 收纳窗口布局纳入设置、备份与恢复；无效显示坐标会在启动时修正到当前工作区。

## 7. 规则优先级

规则决策顺序固定为：

1. 忽略项不进入规则系统。
2. 用户针对单个项目作出的显式选择优先。
3. 数字优先级更高的规则优先。
4. 同优先级同动作可合并解释。
5. 同优先级不同动作产生冲突，必须由用户处理。
6. 未命中规则的项目留在收件箱。

## 8. 异常与边缘场景

- 桌面路径在软件运行期间发生变化。
- 文件扫描后、执行前被用户移动或删除。
- 文件大小仍在增长，说明下载或写入尚未结束。
- 目标目录没有权限、磁盘空间不足或离线。
- 目标存在同名文件或文件夹。
- 批量操作执行到一半时应用退出或系统关机。
- 快捷方式目标失效，但快捷方式文件本身仍有效。
- 文件夹内部含符号链接、联接点或受保护文件。
- 撤销时原位置已被另一个同名项目占用。

## 9. 非功能需求

### 安全性

- 不静默永久删除文件。
- 不默认以管理员权限运行。
- 日志不得存储文件内容。
- 诊断日志必须脱敏个人目录和绝对路径，仅由用户主动导出；导出包不包含设置、操作数据库或授权状态。
- 执行前再次校验源项目状态，防止使用过期计划。
- 收纳窗口的直接操作不经过整理计划；删除固定进入 Windows 回收站，同名目标不得覆盖。

### 性能

- 1000 个桌面项目下，初始列表在 2 秒内可用。
- 规则计划在常规桌面规模下 1 秒内生成。
- 文件监听采用增量更新，避免频繁全量扫描。

### 可靠性

- 文件系统是事实来源，数据库仅保存索引、规则和历史。
- 数据库损坏不能导致用户文件损坏。
- 每个操作项拥有明确的待执行、成功、跳过、失败或已撤销状态。

### 可访问性

- 核心流程可使用键盘完成。
- 不仅依赖颜色表达冲突和状态。
- 支持 Windows 缩放和高对比度模式。

## 10. 信息架构

- **收件箱**：待处理项目与整理入口。
- **收藏夹**：已实现逻辑分组、多标签成员关系和失效路径管理。
- **规则**：规则列表、编辑、排序与测试。
- **规则与收纳**：一个导航入口内提供规则编辑、收纳区映射、逐窗口显示状态、自动排列和外观设置，不提供桌面窗口总开关。
- **历史**：整理结果、失败处理与撤销。
- **设置**：目录、安全、通知和应用行为。

## 11. 成功指标

- 首次用户在 3 分钟内完成一次安全整理。
- 所有计划整理产生的成功移动均可从历史中定位原路径；收纳窗口直接操作即时生效并显示结果。
- 因软件覆盖或永久删除导致的数据丢失为 0。
- 一周后用户桌面待处理项目数量明显下降。
- 用户能够在不阅读帮助文档的情况下解释“计划”和“执行”的区别。

## 12. MVP 验收标准

- 能正确发现桌面文件、文件夹和快捷方式。
- 能创建并测试至少三类规则条件。
- 能生成不修改文件的整理计划。
- 能安全执行批量移动且不覆盖目标文件。
- 能在部分失败时准确展示每项结果。
- 能在应用重启后撤销之前的移动。
- 能处理扫描后源项目已变化的情况。
- 1000 个桌面项目下核心操作保持流畅。

## 13. 后续候选功能

- 桌面侧边抽屉和快速浮窗。
- 重复文件检测。
- 规则模板导入导出。
- OCR 与本地 AI 分类。
- 项目工作区：文件、目录、应用和网站一键打开。
- 跨设备规则同步。
